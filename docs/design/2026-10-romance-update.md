# 설계: 낭만 업데이트

> 이 모드의 중심은 **낭만**이다. 겉날개와 네더 지름길이 없는 대신, 직접 깐 길 위를 달리며 풍경을 본다.
> 이번 업데이트의 모든 결정은 "이동하는 동안 세계를 보게 하는가"로 판단한다.

## 0. 원칙

- **순간이동 없음.** 기존 "급행(웅크리고 승차권 → 일정 시간 뒤 목적지로 이동)"은 이 원칙과 정면으로 부딪히므로 **제거**한다.
  노선 안내(역에서 승차권 → 경로 표시)와 분기기 자동 전환은 그대로 둔다. 실제로 타고 가야 도착한다.
- **차량은 추가하지 않는다.** 바닐라 마인카트·보트·말, 그리고 Create 기차를 쓴다. InfraCraft 는 선로·역·안전장치·설계도만 만든다.
- **명령어 없음.** 블록·아이템 상호작용만.

## 1. 같은 선로 위의 충돌

### 1-1. 바닐라 마인카트: 자동 열차 정지 장치(ATS)

현재 바닐라 카트는 서로 부딪히면 튕겨 나간다. 실제 철도처럼 **앞차를 감지해 스스로 멈추게** 한다.

- InfraCraft 가 매 틱 처리하는 카트는 진행 방향으로 선로를 따라가며(커브·경사 포함) 최대 `atsLookahead`(기본 24)칸 안의 다른 카트를 찾는다.
- **같은 방향 앞차**: 간격 4칸을 유지하도록 속도를 앞차 이하로 제한하고, 3칸 안이면 정지. (역에 정차 중인 앞차 뒤에서 차례를 기다린다.)
- **마주 오는 차**: 둘 다 4칸 앞에서 정지. 멈추는 것은 "상대 쪽으로 가는 속도"만이라, 탑승자가 반대로 몰면(바닐라 조작) 물러날 수 있다.
  탑승자에게 "단선 구간: 맞은편 차량 대기 중" 안내. 해결은 철도처럼 **복선**이나 **교행(분기기)**.
- 끄고 켤 수 있다(`ats`).

### 1-2. Create 기차

- Create 기차끼리 부딪치면 Create 규칙대로 사고(정지·탈선)가 난다. 이를 막는 수단은 Create 자체의 **신호기(폐색 구간)** 와 **운행 일정**이며, InfraCraft 는 이를 대체하지 않는다.
- 대신 InfraCraft 키트가 **애초에 겹치지 않는 구조**를 만든다:
  - 실드 굴진기는 단선 터널(내부 5×5)을 판다. 같은 방향으로 두 번 뚫으면 가운데 벽을 공유하는 **쌍굴 복선**이 된다(상행/하행 분리).
  - 가이드에 "역 앞뒤에 신호기 한 쌍"을 그림과 함께 넣는다.
- Create 기차는 선로 위 사람을 친다. 그래서 **승강장 안전문**을 추가한다(1-3).

### 1-3. 승강장 안전문 (새 블록)

- 승강장 가장자리에 세우는 유리문. 평소에는 닫혀 있어 선로로 떨어지거나 걸어 들어가지 못한다.
- 바로 옆 선로에 **멈춘** 마인카트나 Create 객차가 있으면 열린다(열린 상태는 통과 가능).
- 지하 역사 설계도가 승강장 가장자리에 자동으로 설치한다.

## 2. 역 승강기

순간이동이 아니다. 승강기 블록 위 수직구 안에 선 플레이어를 **실제로 밀어 올린다**(웅크리면 내려감). 올라가는 동안 수직구 벽과 하늘이 보인다. 변경 없음.

## 3. 지하철 차량: Create 블록으로 짓는 "차량 도면"

차량을 새로 추가하지 않고, **Create 기차의 차체를 지어 주는 도면**을 준다. 조립은 Create 방식(역을 조립 모드로 → 조립) 그대로.

- **전동차 도면**: 폭 5 × 길이 9 × 높이 4. 차체는 Create 블록(산업용 철·안산암 케이스·틀 유리·기차 문·좌석·기차 조종기)과 터널 조명.
  양옆 롱시트 좌석, 양쪽 출입문 2개씩, 앞쪽 운전대.
- **객차 도면**: 같은 뼈대에 가문비나무 내장·창문의 옛 객차. 지상 노선용.
- 사용: Create 트랙 위에서 진행 방향을 보고 사용 → 인벤토리의 재료를 소모해 차체를 짓고, 차체 전체에 Create 강력 접착제를 붙인다.
  대차(bogey)는 Create 방식대로 플레이어가 트랙에 기차 케이스를 대어 놓는다(표시된 두 칸).
- Create 가 없으면 도면은 조합법이 없고 사용해도 안내만 한다.
- 규격을 맞추기 위해 **터널 내부 높이 4 → 5**, 역사 승강장을 **차량 바닥 높이(선로 +1)** 로 올린다(턱 없는 승하차).

## 4. 역사 종류 확장

| 설계도 | 쓰는 곳 | 짓는 것 |
|---|---|---|
| 지하 역사 설계도 | 지하 선로 위 | 지하 역사(승강장·안전문·조명·승강기 수직구) — 기존 |
| 지상 역사 설계도 (새) | 지상 선로 위 | 높은 승강장 양쪽, 기둥과 지붕(캐노피), 벤치, 가로등, 역명 이정표 |
| 항구 설계도 (새) | 물가에서 물을 보고 | 나무 잔교, 계선주, 등불, 항구 역 블록(보트 정류장), 교역소 |

## 5. 항구 교역

**배를 타고 실제로 먼 항구까지 가야** 성립하는 교역. 바다를 건너는 여행 자체가 보상이 된다.

1. **특산품**: 항구가 있는 생물 군계로 정해진다(열대우림=코코아 콩·대나무·멜론, 사막=선인장·모래·사암, 눈=얼음·눈덩이·꽁꽁 언 얼음, 해안=대구·연어·켈프 …).
2. **선적**: 교역소에 그 항구의 특산품을 들고 사용 → **화물 상자**(출발 항구·물품·수량이 적힌 아이템)가 된다.
3. **항해**: 화물 상자를 들고(또는 상자 보트에 싣고) 보트로 다른 항구에 도착하면 자동으로 하역·정산된다.
   - 같은 종류의 항구(같은 군계)로는 팔 수 없다. 200블록 미만 거리도 안 된다.
   - 대가: 도착 항구의 특산품. 수량은 거리에 비례(0.6배~2.5배).
   - 먼 항해일수록 **진귀품**(앵무조개 껍데기, 이름표, 스니퍼 알, 바다의 심장 등)을 받을 확률이 오른다.
4. 통계: 교역 횟수, 항해 거리.

## 6. 아이템별 조합법 또는 획득처

모든 아이템은 **조합법 또는 획득처 중 하나**로 얻는다(둘 다인 경우는 적었다).
조합법은 `docs/ITEMS.md` 에 조합대 그림으로 싣는다.

| 아이템 | 얻는 법 |
|---|---|
| 아스팔트, 차선, 가로등, 이정표 | 조합 |
| 고속·특급·블레이즈 선로, 역, 분기기 | 조합 |
| 물살 블록, 보트 리프트, 마구간 | 조합 |
| 터널 라이닝, 터널 조명, 승강장 안전선, 승강장 안전문, 역 승강기 | 조합 |
| 승차권, 도로 포장기, 선로 부설기, 터널 굴착기, 측량기, 호루라기 | 조합 |
| 쇠 편자 | 조합 |
| **다이아몬드 편자** | **획득**: 마을 무기 대장장이·도구 대장장이 상자, 사막 피라미드 상자 |
| 엔더 선로 핵 | 조합(후렴과 구운 후렴과·엔더의 눈 — 사실상 엔드 진출 후) |
| 실드 굴진기, 지하 역사 설계도, 지상 역사 설계도 | 조합 |
| **항구 설계도** | **획득**: 난파선 지도·보급품 상자, 큰 해저 유적 상자 |
| **교역소** | **획득**: 항구 설계도로 지을 때 설치됨(부수면 아이템으로 회수) |
| **화물 상자** | **획득**: 교역소에서 특산품을 선적 |
| 전동차 도면, 객차 도면 | 조합(Create 설치 시에만) |
| 지하철 건설 안내서 | 조합(책 + 선로) |

## 7. 검증

- 단위 수준: 선로 추적(ATS), 교역 정산식은 순수 함수로 분리해 JVM 테스트.
- CI 스모크: 서버 기동 + Create 동반 기동에서 리플렉션 대상(강력 접착제 엔티티, 블록 ID) 확인.
- 게임 안 확인이 필요한 것(안전문 열림, 차체 조립, 항해 정산)은 체크리스트로 남긴다.
