# 실제 게임 화면

CI 의 클라이언트 게임테스트(`./gradlew :mc26.2:runClientGameTest`, `versions/26.2/src/gametest`)가 실제 게임을 띄워 월드를 만들고 찍은 화면이에요.
다시 만들려면 게임테스트를 돌린 뒤 `python3 tools/screenshots.py`.
