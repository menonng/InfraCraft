# InfraCraft

교통 인프라를 중심으로 하는 Fabric 모드예요. 겉날개와 네더 8배 지름길을 없애는 대신, **직접 깐 도로·철도·운하가 곧 이동 속도**가 되도록 만들었어요. couriersroost 와 함께 쓰는 것을 염두에 두었어요.

이 모드의 중심은 **낭만**이에요. 하늘을 날거나 포탈로 건너뛰면 세계를 볼 틈이 없어요. 그래서 InfraCraft 에는 **순간이동이 없어요.** 기차 창밖으로, 배 위에서, 말 등에서 풍경을 보며 직접 가야 도착해요.

**차량(기차·보트·비행선 등)은 추가하지 않아요.** 기본적으로 [Create](https://github.com/Creators-of-Create/Create)(26.x Fabric 은 Create Fly)와 그 애드온이 차량을 맡는다고 보고, InfraCraft 는 그 차량이 달릴 인프라와 노선망을 만들어요.

| 마인크래프트 | Java | Fabric API | 고른 이유 |
|---|---|---|---|
| **26.3** | 25 | 0.165.0+26.3 | 최신 버전. Create Fly 비공식 26.3 포트와 함께 쓰는 것을 확인했어요 |
| **26.2** | 25 | 0.161.0+26.2 | Create Fly 애드온 포트가 가장 많은 버전. 공식 Create Fly 26.2 + Steam 'n' Rails 와 함께 쓰는 것을 확인했어요 |

언어는 Kotlin(fabric-language-kotlin 1.14.2)이에요. 어느 버전을 고를지는 [docs/CREATE_ADDONS.md](docs/CREATE_ADDONS.md)의 애드온 목록을 보고 정하면 돼요.

Create 의 Ponder 처럼 **기능마다 짧은 영상**이 있어요. 게임의 실제 텍스처와 마인크래프트·Create 의 실제 효과음으로 만들었어요.

기능별 가이드 15편(도로·옛길, 등급 선로, 역·승차권·분기기, ATS, 노선망, 실드 굴진기, 지하·지상 역사, 차량 도면, 항구, 다리 키트, 수운, 말, 건설 장비, 네더, 인챈트)은 **[docs/VIDEOS.md](docs/VIDEOS.md)** 에 있어요.
영상은 코드로 그린 장면을 CI 가 게임 파일의 텍스처·소리로 렌더링해요(`tools/video`, `videos` 워크플로).

## 기본 규칙
- **겉날개 금지**: 활공이 막히고, 손에 들어온 겉날개는 *엔더 선로 핵*(특급 선로 재료)으로 바뀌어요.
- **네더 1:1**: 포탈 좌표 배율이 1이 돼요. 네더는 지름길이 아니라 *블레이즈 선로*를 깔 수 있는 위험한 고속 노선이에요.

## 기능
### A. 도로
- 도로 등급 1(흙길·자갈), 2(석재·벽돌), 3마다 이동 속도 보너스가 있어요. 3등급은 아스팔트·차선뿐 아니라 손으로 놓은 **옛길**(포석길·벽돌 포장길·판석길)도 있어요. 정취는 달라도 속도는 같아요. 보너스는 연속된 도로 위에서 서서히 쌓이고, 도로를 벗어나면 서서히 빠져요.
- 걷는 플레이어와 타고 있는 말 모두에게 적용돼요.
- **이정석**: 길가에 세우는 낮은 돌기둥이에요. 곁을 지나가면 가까운 역 두 곳의 방향과 거리가 떠요.
- **이정표**: 맨손으로 우클릭하면 가까운 역 다섯 곳의 방향과 거리를, 웅크리고 우클릭하면 노선망 요약과 전체 역 목록을 보여줘요. **가로등**도 있어요.

### B. 철도
- **고속 선로**(0.6), **특급 선로**(0.8), **블레이즈 선로**(네더 전용, 1.1) — 단위는 블록/틱이고, 바닐라는 0.4예요. 커브, 경사, 선로 끝 앞에서는 자동으로 감속해요.
- **역**: 선로 아래에 두면 정차역이 돼요. 승차권 목적지가 이 역이면 정차하고, 아니면 통과해요.
- **승차권**: 허공에 우클릭하면 목적지를 순환해요. 빈 승차권으로 역을 우클릭하면 그 역이 목적지가 되고, 목적지가 있으면 그 역에서 가는 경로를 보여줘요. 마인카트에 우클릭하면 화물 운송장처럼 써요.
- **분기기**: 갈림길 선로 아래에 둬요. 승차권으로 우클릭해서 목적지를 등록하면, 그 목적지로 가는 카트가 올 때 레드스톤 신호를 내서 선로를 전환해요.
- **ATS(자동 열차 정지)**: 바닐라 카트끼리 부딪쳐 튕겨 나가지 않도록, 카트가 선로를 따라 앞 24칸을 살펴요. 앞차가 있으면 4칸 간격을 두고 따라가거나 멈췄다가, 앞이 비면 다시 출발해요. 단선에서 맞은편 차가 오면 둘 다 8칸 앞에서 서요(뒤로는 물러날 수 있어요). 설정 `ats` 로 끌 수 있어요.
- 사람이 타지 않은 채 달리는 카트는 주변 청크를 로드해요.

### C. 노선망
- 탈것이 역 A에서 역 B까지 **실제로 달리면** 그 구간이 노선으로 기록돼요(Create 기차·마인카트·보트·포탈). 노선이 지나는 청크에서 선로를 부수면 그 노선은 끊긴 것으로 처리돼요.
- 예전의 "급행"(기다리면 목적지로 옮겨 주는 기능)은 **없앴어요.** 노선망은 길을 알려 줄 뿐, 가는 건 직접 타고 가요.
- 명령어는 없고, 모두 블록 상호작용으로 써요.
  - **이정표** 클릭: 가까운 역. 웅크리고 클릭하면 노선망 요약과 전체 역 목록
  - **승차권으로 역 클릭**: 승차권 목적지까지 가장 빠른 경로. 승차권이 비어 있으면 이 역을 목적지로 정해요(InfraCraft 역 블록과 Create 기차 정거장 모두)
  - **승차권으로 분기기 클릭**: 그 목적지로 가는 카트를 갈림길에서 돌려요
- 이름표로 역을 우클릭하면 역 이름이 바뀌어요.

### D. 건설 장비
- **도로 포장기**: 우클릭으로 켜고 끄고, 걸으면서 왼손 블록을 폭 3칸으로 깔아요. *넓은 포장* 인챈트로 5칸, 7칸까지 넓어져요.
- **선로 부설기**: 걷는 자리에 선로를 놓아요.
- **터널 굴착기**: 클릭한 면을 3×3으로 파요. *굴착 반경* 인챈트로 5×5, 7×7까지 넓어져요.
- **측량기**: 두 지점을 찍으면 거리, 높이, 경사, 교량에 드는 블록 수를 알려줘요. 두 번째 지점을 웅크리고 찍으면 폭 3칸 교량을 놓아요. 말에게 쓰면 능력치를 알려줘요.

### E. 말
- **편자**(철·다이아몬드)를 박으면 도로 보너스가 커져요.
- **호루라기**: 말에게 우클릭해서 묶고, 허공에 쓰면 말이 달려와요.
- **마구간**: 말을 탄 채 우클릭하면 말을 맡기고, 빈손으로 우클릭하면 꺼내요.

### F. 수운
- **물살 블록**: 위쪽 물에 있는 보트와 엔티티를 바라보는 방향으로 밀어요.
- **보트 리프트**: 위쪽 물기둥에 있는 것을 올려요. 웅크리면 내려가요.
- 물속에 둔 역은 **항구**가 돼요. 보트가 그 위에 닿으면 도착이에요.
- 설정으로 얼음 위 보트 속도에 상한을 걸 수 있어요.

### H. 역사 세 가지
| 설계도 | 쓰는 곳 | 짓는 것 |
|---|---|---|
| 지하 역사 설계도 | 지하 선로 위 | 높은 승강장, 승강장 안전문, 조명, 지상까지의 승강기 수직구 |
| 지상 역사 설계도 | 지상 선로 위 | 높은 승강장 양쪽, 기둥과 가문비나무 지붕, 벤치, 매달린 등불, 이정표 |
| 항구 설계도 | 물가에서 물을 보고 | 나무 잔교와 기둥, 난간과 등불, 계선주, 물속 항구 역(보트 정박) |

승강장은 선로보다 한 칸 높아서, Create 차량 바닥과 턱 없이 이어져요. 항구 설계도는 조합할 수 없고 **난파선·해저 유적·어부 집 상자**에서 찾아요.

### I. 다리 키트
벼랑 끝이나 물가에 서서 건너편을 바라보고 쓰는 키트예요. **내구도 30**이고, 다리를 한 번 놓을 때마다 1씩 닳아요.
- **오른손에 들고 있으면** 다리가 놓일 자리(상판 가장자리·기둥 자리)가 입자로 보이고, 길이·기둥 수·필요한 재료(보유량)가 화면에 떠요. 재료가 모자라면 빨갛게 보여요.
- **높이는 플레이어 발밑을 따라요.** 방향은 바라보는 쪽, 다리는 앞쪽 땅이 끝나는 곳에서 시작해 건너편 땅에 닿는 곳(최대 64칸)에서 끝나요. 아직 닿지 않았으면 끝에 서서 이어 놓으면 돼요.
- **근처에 길**(흙길·자갈·돌 벽돌·아스팔트·옛길 등 도로 등급 블록)이 있으면 그 길의 가운데에 맞춰 옆 위치를 자동으로 보정해요.
- 바닥까지 **5칸 이상** 높은 자리에는 **기둥(교각)**을 세워요. 물속이면 강바닥까지 내려가요.
- 디자인이 여러 블록으로 되어 있어도 **인벤토리의 원재료 한 종류만** 써요(놓이는 블록 하나당 원재료 하나, 왼손 → 인벤토리 순서로 골라요).

| 키트 | 원재료 | 모습 |
|---|---|---|
| 목조 다리 키트 | 판자 한 종류(참나무·가문비·진홍 …) | 판자 상판, 울타리 난간과 통나무 기둥, 상판 아래 통나무 보, 높은 곳엔 통나무 가대 |
| 석조 아치교 키트 | 담장이 있는 석재 한 종류(석재 벽돌·조약돌·벽돌·사암·심층암 타일 …) | 담장 난간, 교각 사이를 잇는 계단 아치, 상판 폭 그대로의 석조 교각 |
| 구리 트러스교 키트 | 깎인 구리 한 종류(녹슨 정도 그대로) | 4칸마다 세운 기둥과 위 현, 창살 난간, 격자 장식, 머리 위 문형 보 |

### G. 네더
- **블레이즈 선로**는 네더에서만 가속하고, 블레이즈 가루 1개로 128블록을 달려요.
- 포탈 양쪽 16블록 안에 역이 있으면 포탈 노선으로 이어져요.

### 지하철 제작 키트
- **기본이 복선이에요.** 두 선로 사이 가운데에 서서 쓰면, 상행·하행이 한 줄씩 깔려 서로 마주치지 않아요.
- **실드 굴진기**: 폭 11 × 높이 5 복선 터널 단면을 한 칸씩 뚫고 라이닝, 선로 두 줄(Create 트랙 우선, 없으면 바닐라 선로), 조명을 깔아요. 아래나 위를 보고 쓰면 경사 터널이에요.
- **지하 역사 설계도**: 상대식 승강장 둘(선로보다 한 칸 높음), 승강장 안전문, 조명, 양쪽 승강장의 승강기 수직구를 한 번에 지어요. Create 트랙이면 Create 기차 정거장을 놓을 자리를, 바닐라 선로면 InfraCraft 역 블록까지 놓아요.
- **역 승강기**는 순간이동이 아니에요. 수직구 안에서 플레이어를 실제로 밀어 올려요(웅크리면 내려가요).
- **승강장 안전문**: 평소엔 닫혀 있어 선로로 떨어지거나 걸어 들어가지 못하고, 바로 앞에 마인카트나 Create 객차가 멈추면 열려요.
- **전동차 도면 / 객차 도면**(Create 필요): Create 트랙 위에서 쓰면 Create 블록(산업용 철·창·기차 문·좌석·기차 조종기)으로 폭 5 × 길이 9 차체를 짓고 강력 접착제를 붙여요. 표시된 두 칸에 기차 케이스로 대차를 놓고 Create 역에서 조립하면 지하철·객차가 돼요. 차량 자체는 Create 기차예요.
- **터널 라이닝, 터널 조명, 승강장 안전선, 역 승강기** 블록

### 같은 선로 위의 충돌
- **바닐라 카트**: ATS 가 앞차를 감지해 멈춰요(위 B 참고).
- **Create 기차**: 서로 부딪치면 Create 규칙대로 멈추고 탈선해요. Create 의 **기차 신호기**(폐색 구간)와 **운행 일정**으로 막아요. InfraCraft 키트는 기본이 복선(상행·하행 분리)이고 역마다 안전문이 있어 애초에 겹치지 않는 구조를 만들어요.
- 가이드: 책 + 레일로 만드는 「지하철 건설 안내서」(게임 안), [docs/SUBWAY_GUIDE.md](docs/SUBWAY_GUIDE.md)

## 인챈트·스탯
| 방식 | 내용 |
|---|---|
| 바닐라 레벨 확장 | 영혼 가속 V, 차가운 걸음 III, 가벼운 착지 V (`extendedEnchantLevels` 로 조정) |
| 새 인챈트(속성 경로) | **로드러너**(신발): `infracraft:road_affinity` 속성을 올려 도로 보너스를 키워요 |
| 새 인챈트(코드 경로) | **관성**(바지), **기수**(바지), **차장**(투구), **넓은 포장**, **굴착 반경**, **절약** |
| 아이템 지정 | 편자 → 말에 영구 기록, 승차권 → 카트 목적지, 블레이즈 가루 → 연료 |
| 통계 | 도로 이동 거리, 역 도착, 측량한 노선, 부설한 선로, 포장한 블록, 굴착한 블록, 말 부른 횟수, 다리에 놓은 블록 |

## 모드팩
InfraCraft 와 Create Fly 26.2 애드온을 한데 묶은 Modrinth 모드팩(.mrpack)을 CI 로 만들어요(`modpack` 워크플로, 목록은 `tools/modpack/pack.json`). 한국어가 빠진 모드는 원작 Create 애드온의 한국어로 채운 리소스팩이 함께 들어가요. 자세한 내용은 **[docs/MODPACK.md](docs/MODPACK.md)**.

## 아이템 조합법·획득처
모든 아이템은 **조합하거나, 또는 다른 곳에서 얻어요.** 조합법은 조합대 그림과 함께 **[docs/ITEMS.md](docs/ITEMS.md)** 에 있어요.
조합할 수 없는 것: 다이아몬드 편자(마을 대장간·사막 피라미드 상자), 항구 설계도(난파선·해저 유적·어부 집 상자).

## 설정
`config/infracraft.json` 에서 모든 수치(속도, 보너스, 겉날개 금지, 네더 1:1, 확장 인챈트 레벨 등)를 바꿀 수 있어요.

## 빌드
```
./gradlew buildAll                 # 두 버전 모두
./gradlew :mc26.2:build            # 하나만
```
결과물은 `versions/<버전>/build/libs/` 에 생겨요. 텍스처와 데이터 JSON 은 `tools/gen_textures.py`, `tools/gen_data.py` 로 다시 만들 수 있어요(번역 원본은 `tools/lang.json`).

## 구조
- `common/kotlin` — 세 버전이 함께 쓰는 Kotlin 코드
- `versions/<버전>/src/main/kotlin/.../compat/Compat.kt` — 버전마다 다른 API 를 감싸는 얇은 계층
- `versions/<버전>/src/main/java/.../mixin` — 마인카트 최고 속도, 네더 배율, 인챈트 최대 레벨 믹스인
